# 매듭 교실 — 한 단계씩 배우는 매듭

생존·탈출·생활에 쓰이는 매듭 10가지를 단계별 애니메이션으로 배우는 웹앱입니다.

👉 **https://jihye84.github.io/knots/**

## 기능

- **처음 화면:** 매듭 10가지의 완성(조여진) 모양을 카드로 한눈에 펼쳐 보여 줍니다. 카드를 눌러 들어가고, 왼쪽 위 '매듭 교실'을 누르면 처음 화면으로 돌아옵니다.
- **쉬운 매듭부터:** 매듭을 세 분류로 나누고, 분류마다 쉬운 것부터 보여 줍니다. 이름 옆 별(★1~3)이 난이도예요.
  - 🏕️ 생존·야외: 옭매듭, 8자 매듭, 클로브 히치, 투 하프 히치
  - 🚨 탈출·구조: 시트 벤드, 보라인, 이중 시트 벤드
  - 🏠 생활 편의: 맞매듭, 슬립 노트(풀매듭), 타우트라인 히치
- **그라데이션 줄:** 고정된 쪽은 파란색, 움직이는 끝은 빨간색으로 칠해서 어느 부분이 어디로 지나가는지 알아보기 쉽습니다. 위로 지나가는 줄과 밑으로 지나가는 줄을 구분해 그립니다.
- **단계별로 보기 / 이어 보기:** 이전·다음 버튼으로 한 단계씩 넘기거나 처음부터 끝까지 이어서 볼 수 있습니다. 점선 화살표가 다음 단계에서 줄 끝이 갈 길을 미리 보여 줍니다. 속도는 세 가지(느리게·보통·빠르게) 중에서 고릅니다.
- **당겨 조이기:** 마지막 단계에서 줄 끝을 당기면 매듭이 조여지는 모습을 보여 줍니다. 이 모습은 줄이 늘어나거나 서로 뚫고 지나가지 않게 하고, 컴퓨터가 줄 끝을 실제로 당겨 보며 계산한 결과입니다. 마찰은 계산하지 않아서 실제 줄과 조금 다를 수 있습니다.
- **매듭 정보:** ⓘ 버튼을 누르면 매듭마다 '이럴 때 써요 / 외우는 요령 / 조심할 점'이 나옵니다.
- **어떤 화면에서도:** 휴대폰·태블릿·노트북·교실 TV 어디서나 스크롤 없이 보입니다. 키보드는 ←, →, 스페이스바로 조작합니다.
- **인앱 브라우저 탈출:** 카카오톡·네이버·페이스북 등 앱 안에서 열면 기본 브라우저로 다시 엽니다. 아이폰은 자동으로 넘어가지 않아 "Safari로 열기" 안내 화면이 뜹니다.

## 주의

사람의 몸무게를 거는 매듭(보라인 등)은 반드시 훈련받은 사람에게 직접 배우고 확인받으세요. 이 앱은 매듭 모양을 익히는 학습용입니다.
